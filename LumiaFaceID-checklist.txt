[x] Android lists three cameras; iris is camera ID 2. The normal rear and front camera slots remain separate.
[x] Fixed camera ordering so the stock camera app uses the normal front camera.
[x] Opened the iris with Camera2 and received 1920x1080 YUV frames. Current-source checks matched image and capture-result timestamps and handled the reported crop.
[x] Added probe controls for preview orientation/aspect ratio and manual exposure/sensitivity diagnostics.
[x] Kept the Windows 10 Mobile FFU and private iris sensor profile locally. Firmware analysis and hashes are recorded; do not delete either file.
[x] Mapped key Windows iris components, including the sensor driver, camera authentication capture path, WinBio adapter and iris engine interfaces.
[x] Confirmed the sensor reports no strobe capability; sensor strobe is not the illumination path. Windows analysis points to host/camera-driver flash scheduling, whose exact IR-channel consumer and timing are unresolved.
[x] Recorded one bounded minimum torch_0 pulse and an illuminated frame with higher signal. It did not establish a usable eye region, optical timing or eye-safe limits.
[x] Verified camera teardown and LED cleanup after recorded tests; recent readback showed all cameras closed and all four LED channels at 0.
[x] One latest IR-off frame arrived, but was nearly black (luma p95=2); it did not show usable iris detail.
[x] Added a range-clamped manual exposure selector. IR-off phone validation confirmed Camera2 exposure results at 50, 75, 100, 200 and 300 ms; 300 ms / ISO 800 produced luma p95=47, but no face-derived eye ROI.
[x] Reviewed Android 16 iris framework and Keyguard gaps against the installed phone and pinned Lineage source.
[x] Drafted framework patches 0003-0007 for iris registration, Keyguard result/request plumbing and a gated Keyguard lifecycle hook. Patch application/diff checks passed on disposable source copies.

WORKING RULES
- Local work only. Do not push to GitHub or create a PR unless explicitly asked.
- For kernel experiments, use temporary boot only; never flash a test kernel.
- Never stream the iris and normal front camera together; they share CSIPHY2.
- After any emitter test, stop capture and verify torch_0, torch_1, flash_0 and flash_1 are all off.
- Never point IR at a person or eye; do not test inside a metal can or reflective enclosure. Use only a confirmed diffuse target and bounded pulses.
- Keep the original FFU and private sensor profile.
